# [Tinker Store](https://tinkerstore.tech/) Frontend

Tinker Store is an E-commerce platform build to learn development of a fullstack project. The application provides a responsive interface for browsing products, managing carts, placing orders, authenticating users, and interacting with the backend APIs. It is designed to work alongside the Tinker Store backend, which handles business logic, authentication, data persistence, caching, and API services.

## Features

- Product browsing and search
- User authentication
- Shopping cart management
- Order placement and tracking
- Responsive UI
- REST API integration

## Tech Stack
- Solid.js
- Tailwind
- Clerk (Authentication)
- ImageKit (CDN for images)
